# Thaumaturge Tech Compats

Avaritia content for **Thaumaturge**, ported from the Thaumcraft compat of the original Avaritia, for NeoForge 1.21.1 on top of **Re:Avaritia**.

## Features

* **Terminus**, a new aspect (Desiderium + Alienis).
* **Akashic Records**, an item that adds 999 points of every aspect to your aspect pool.
* **Extremely Primordial Pearl**, infused from Primordial Pearls; it is not consumed when crafting.
* **Infinity wand rod** and **Crystal Matrix wand cap**: the rod refills every primal aspect, the cap makes casting free. The wand is crafted in the Extreme Crafting Table.
* Thaumonomicon pages for all of them, in the Eldritch category.
* Terminus and other aspects for the Avaritia items.

## Requirements

* NeoForge for Minecraft 1.21.1
* Thaumaturge
* Re:Avaritia

## Branches

* `Neo/1.21.1` — Minecraft 1.21.1
